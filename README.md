# TextileMap_Team11

Static project website for Team 11's Capstone Project.

## Files
- `index.html` – page content and structure
- `style.css` – all styling and responsive layout
- `script.js` – menu, scroll animations and small interactions
- `assets/` – add images/diagrams/logo here

## Run locally
Open `index.html` in your browser.

For easier local development, you can also use the VS Code extension "Live Server".

## Before submission
1. Add the official Chalmers logo to `assets/chalmers-logo.png`
2. Replace the text-based logo block in `index.html` with the `<img>` line already included in the comment
3. Add exact course title/course code
4. Add one or two contact representatives and their real email addresses
5. Replace both sustainability diagram placeholders with your actual diagrams
6. Add complete references with titles, authors/organizations, years and URLs/DOIs
7. Replace any illustrative prototype values if you later have real or agreed demo data
8. Publish through GitHub Pages
